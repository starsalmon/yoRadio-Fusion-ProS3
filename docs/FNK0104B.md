# Freenove FNK0104B (yoRadio Fusion)

PlatformIO env: **`freenove-fnk0104b`** · board header: [`boards/fnk0104b.h`](../boards/fnk0104b.h)

Cain’s unit (ESP32 Helper): **ESP32-S3R8**, 8 MB **OPI PSRAM**, 16 MB flash. MAC `84:c7:bb:78:2a:bc` (for humans only — not baked into firmware).

## Build / flash (when Cain approves)

```bash
pio run -e freenove-fnk0104b
# Upload (later, on bench — not automated by agents):
pio run -e freenove-fnk0104b -t upload
```

Typical USB port on Mac: `/dev/cu.usbmodem1101`. App partition offset **0x10000** (standard Arduino OTA layout in this repo).

## Pin map (2.8" ILI9341 kit)

| Function | GPIO | Notes |
|----------|------|--------|
| TFT SCLK / MOSI / MISO / CS / DC | 12, 11, 13, 10, 46 | RST unused (-1) |
| Backlight | 45 | active HIGH |
| I2C SDA / SCL | 16, 15 | FT6336U, ES8311, MPU6050 |
| Touch INT / RST | 17, 18 | FT6336U |
| I2S MCLK / BCLK / WS / DOUT / DIN | 4, 5, 7, 8, 6 | ES8311 |
| Amp enable (AP_ENABLE) | 1 | **LOW** at boot = muted; **HIGH** while playing (same idea as `MUTE_PIN` on ProS3 / April’s Speaker) |
| SDMMC CLK/CMD/D0–D3 | 38, 40, 39, 41, 48, 47 | Not shared with TFT SPI |
| WS2812 | **42** | Bruce samples use GPIO **40** on some builds |
| BOOT (mode) | 0 | Must not be held low at power-up |
| Battery ADC | **9** (2:1 divider) | Bruce uses GPIO **8** on some sketches |

**Display:** Adafruit ILI9341 @ **40 MHz** SPI (80 MHz glitches). Inversion **on**, **BGR** order. Do **not** enable TFT_eSPI DMA on this panel.

## Audio (ES8311)

- Vendored Freenove / Espressif driver under [`src/boards/fnk0104b/`](../src/boards/fnk0104b/) with **Wire** I2C (shared with touch).
- Init runs from `player.init()` after I2S pinout; failure logs and continues boot.
- Codec volume tracks yoRadio UI volume; I2S sample-rate changes may need further `es8311_sample_frequency_config` hooks (TODO when streaming non-44.1 kHz sources).

## SD card

- **SDMMC 4-bit** path via `YORADIO_SD_MMC` — ProS3/April **SPI** SD unchanged.

## Touch

- **FT6X36** driver enabled (`TS_MODEL_FT6X36`). Coordinate mapping reuses existing `touchscreen.cpp` transforms; may need `fliptouch` tuning on hardware.

## MPU6050 (optional)

Constants in board header: screen X = **+Z**, screen Y = **−Y**. No auto-rotate task on `main` yet — **TODO**.

## Safety
