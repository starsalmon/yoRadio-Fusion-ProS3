# Freenove FNK0104B (yoRadio Fusion)

PlatformIO env: **`freenove-fnk0104b`** · board header: [`boards/fnk0104b.h`](../boards/fnk0104b.h)

Cain’s unit (ESP32 Helper): **ESP32-S3R8**, 8 MB **OPI PSRAM**, 16 MB flash. MAC `84:c7:bb:78:2a:bc` (for humans only — not baked into firmware).

## Build / flash

```bash
pio run -e freenove-fnk0104b            # app
pio run -e freenove-fnk0104b -t buildfs # SPIFFS (www, data, logos)
```

First flash over other firmware (different partition table): write the full image, keeping the
built headers (the builder writes the bootloader as **DIO**; forcing `--flash-mode qio` on the
bootloader makes the S3 ROM boot-loop with `ets_loader.c 78`):

```bash
B=.pio/build/freenove-fnk0104b
esptool --chip esp32s3 --port /dev/cu.usbmodem1101 -b 921600 write-flash \
  --flash-mode keep --flash-freq keep --flash-size keep \
  0x0 $B/bootloader.bin 0x8000 $B/partitions.bin \
  0xe000 ~/.platformio/packages/framework-arduinoespressif32/tools/partitions/boot_app0.bin \
  0x10000 $B/firmware.bin 0xA10000 $B/spiffs.bin
```

After that, app-only updates go to **0x10000**. Typical USB port on Mac: `/dev/cu.usbmodem1101`
(native USB-Serial/JTAG: opening the port resets the board). Long `read-flash` with the esptool
stub drops out on this board ("serial noise"); `--no-stub` in 1 MB chunks is reliable.

## Pin map (2.8" ILI9341 kit)

| Function | GPIO | Notes |
|----------|------|--------|
| TFT SCLK / MOSI / MISO / CS / DC | 12, 11, 13, 10, 46 | RST unused (-1) |
| Backlight | 45 | active HIGH |
| I2C SDA / SCL | 16, 15 | FT6336U, ES8311, MPU6050 |
| Touch INT / RST | 17, 18 | FT6336U |
| I2S MCLK / BCLK / WS / DOUT / DIN | 4, 5, 7, 8, 6 | ES8311 |
| Amp enable (AUDIO_EN) | 1 | Wired straight to FM8002E **SHUTDOWN**: **HIGH = amp off**, **LOW = amp on** (`MUTE_VAL HIGH`) |
| SDMMC CLK/CMD/D0–D3 | 38, 40, 39, 41, 48, 47 | Not shared with TFT SPI |
| WS2812 | **42** | Bruce samples use GPIO **40** on some builds |
| BOOT (mode) | 0 | Must not be held low at power-up |
| Battery ADC | **9** (2:1 divider) | Bruce uses GPIO **8** on some sketches |

**Display:** Adafruit ILI9341 @ **40 MHz** SPI (80 MHz glitches). Glass needs inversion **on** (`YORADIO_ILI9341_INVERT_ON`; the *invert display* setting toggles relative to it), **BGR** order (Adafruit default). Do **not** enable TFT_eSPI DMA on this panel.

## Audio (ES8311)

- Vendored Freenove / Espressif driver under [`src/boards/fnk0104b/`](../src/boards/fnk0104b/) with **Wire** I2C (shared with touch).
- Init runs from `player.init()` after I2S pinout; failure logs and continues boot.
- Codec DAC is fixed at 0 dB (`ES8311_DAC_VOLUME`); yoRadio volume is applied digitally in Audio only; I2S sample-rate changes may need further `es8311_sample_frequency_config` hooks (TODO when streaming non-44.1 kHz sources).

## SD card

- **SDMMC 4-bit** path via `YORADIO_SD_MMC` — ProS3/April **SPI** SD unchanged.

## Touch

- **FT6X36** driver enabled (`TS_MODEL_FT6X36`). Coordinate mapping reuses existing `touchscreen.cpp` transforms; may need `fliptouch` tuning on hardware.

## MPU6050 auto-rotate + fluid gravity

MPU6050 at 0x68 on the **same** I2C bus as touch and the ES8311 (SDA16/SCL15). `ORIENT_SHARED_WIRE 1`:
orient uses the already-begun `Wire` and never begins, re-clocks or ends it (Wire's per-task
transaction lock keeps reads atomic). 180° only, like the radio (`rotmode` / `rotlock` over MQTT/web).

Mount (edge-on): sensor X = screen normal. GoL measured screenX=+Z, screenY=-Y at TFT_eSPI rotation 1;
yoRadio's base rotation is 3, so `ORIENT_H_AXIS 2`, `ORIENT_V_AXIS 1`, `ORIENT_N_AXIS 0`, no inverts.
Water/rotation mirrored left-right: `ORIENT_INVERT_X 1`; upside down: `ORIENT_INVERT_Y 1`.

## Screensavers

Fluid / Game of Life as on the radio (docs/SCREENSAVERS.md): 320x240 ILI9341, buffers in (OPI) PSRAM,
40 MHz SPI, no DMA.

## MQTT / Home Assistant

Uses the shared gitignored `mqttoptions.h` (copy it into a worktree; never commit it). The board sets
`BOARD_MQTT_ROOT_TOPIC "yoradio/fnk0104b/"` so it never shares topics with the radio; HA unique_ids
come from the mDNS name `yoradio-<chipid>`.

## Safety

Do **not** OTA/flash this image over other bench firmware (e.g. GoL) until Cain confirms the bot/display stack is idle and safe.
